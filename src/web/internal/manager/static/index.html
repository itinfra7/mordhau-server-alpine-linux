IPv4 · IPv6 · IPv4 RANGES

Network access policy

Rule precedence: the longest matching prefix wins; deny wins a same-prefix tie. Inclusive IPv4 ranges are evaluated as exact minimal CIDR blocks. When “Deny all” is selected, the current client receives a 30-minute exact-address emergency allow rule that temporarily overrides conflicts and expires automatically.

Accepts a single IPv4 or IPv6 address, a CIDR network, or an inclusive IPv4 range using start-end or start~end. Comments are optional and limited to 160 characters.
